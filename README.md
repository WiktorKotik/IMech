# ИМЭЧ — конкурсное задание (спринт-3)

Учебный проект по МДК.01.03 «Разработка мобильных приложений»:
выполнен спринт-3 конкурсного задания.

## Что реализовано

- **SplashScreen** — логотип и переход к онбордингу (только при первом запуске) или к последнему экрану.
- **Три приветственных экрана** — HorizontalPager, есть пропуск всего приветствия.
- **Регистрация** — надпись Create Account закреплена сверху, контент скроллится; проверка email
  по паттерну «name@domenname.ru» (только маленькие буквы и цифры); показ пароля.
- **Авторизация** — экран Log In, ошибки сервера показываются уведомлением.
- **Landing Screen** — «гамбургер» открывает меню слева с анимацией, закрытие свайпом влево
  или крестиком; центральная кнопка нижнего меню открывает Schedule Game.
- **Schedule Game** — дата и время через стандартные DatePicker и TimePicker;
  игра сохраняется на сервере (имитация REST API), после Publish открывается Success,
  затем возврат на Landing.
- **Клиент-серверное взаимодействие (модуль В)** — все запросы идут через абстракцию
  RemoteDataSource; ошибки сервера и отсутствии сети показываются уведомлением
  на 5 секунд с кнопкой закрытия.
- **Хранение информации (модуль Г)** — состояние последнего экрана сохраняется и
  восстанавливается после перезапуска; Политика конфиденциальности и Пользовательское
  соглашение открываются из меню (файлы privacy_policy и terms_of_use в assets приложения; PDF открывается внешним просмотрщиком, текстовая версия — на экране).

## Архитектура (модуль А)

Слои DOMAIN / PRESENTATION / DATA разделены по папкам:

```
app/src/main/java/com/example/imech/
├── domain/                  # ядро приложения: модели, use case'ы, интерфейсы
│   ├── exception/
│   ├── model/
│   ├── repository/
│   └── usecase/
├── data/                    # данные: REST API, локальное хранилище, мапперы
│   ├── local/
│   ├── mapper/
│   ├── remote/
│   └── repositoryImpl/
└── presentation/            # UI: экраны, ViewModel'ы, тема, компоненты
    ├── components/
    ├── navigation/
    ├── screens/
    ├── theme/
    └── viewmodels/
```

Для каждого класса добавлены структурированные комментарии (описание назначения,
дата создания, автор). Изменение одного экрана не влияет на остальные.

## Требования

- Android Studio (Kotlin 2.0, JDK 17)
- Минимальная версия ОС: Android 14.0 (API 34) — по условию конкурсного задания

## Как запустить

1. Открыть проект в Android Studio.
2. Дождаться синхронизации Gradle.
3. Run ▸ Run 'app'.

## Git (модуль Г)

- Работа ведётся в ветке `sprint-3`;
- коммит с задачей переносится в колонку «Готово к тестированию» с указанием хеша коммита;
- после проверки создаётся pull request ветки `sprint-3` в `main` и закрывается.
